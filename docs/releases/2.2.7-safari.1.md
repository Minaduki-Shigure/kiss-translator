# Kiss Translator 2.2.7-safari.1 · macOS

基于上游正式版 [v2.2.7](https://github.com/fishjar/kiss-translator/releases/tag/v2.2.7)，合并 v2.2.6 与 v2.2.7 的更新。Safari 构建号为 `2020701`，支持 Apple Silicon 和 Intel。使用 Minaduki Technologies LLC 的 Developer ID Application 证书签名，App 与 DMG 分别通过 Apple 公证并装订票据。

- 支持自选译文样式快捷轮换，原文与译文均可高亮收藏生词。
- 改善延迟加载 iframe、触屏翻译及浮窗，修复流式富文本占位符和 LINE 译文换行。
- 修复 YouTube 字幕消息处理及原生字幕反复出现的问题。
- 保留 Safari 的扩展存储、后台跨域和流式请求、包内 MAIN world 注入，以及导入配置的平台能力检查。新增的插件 Origin 规则管理会跳过 Safari 不支持的插件，并在拒绝插件运行后避免产生规则副作用。
- 补全上游图片设置缺失的日语、韩语、土耳其语和越南语标签，并修正与上游界面变化不一致的测试。

之前提前采用的浮窗定位、面板测试和网页消息权限修复已经包含在上游正式版中，基线和回移记录见 `safari.config.json`。

**升级前先导出配置。** 退出容器 App，将新版拖入“应用程序”替换旧版，推出 DMG 后再打开，检查扩展启用状态、翻译服务和网站授权，并刷新网页。使用更早个人开发签名版的用户请留意安装说明中的跨签名团队升级提示。

需要 Safari 18.4 或更新版本。LocalAI、外部服务插件和 PDF/EPUB 文件桥仍待移植，上游新增的本地 WebGPU 版面分析不随本次 Safari 升级开放。依赖 Origin / CSP 响应头改写的接口仍有 WebKit 平台限制。隔离 WebKit 验证覆盖核心翻译路径，实际网站和第三方服务仍需结合使用环境核实。

签名私钥和公证凭据仅保存在本机钥匙串。GitHub CI 执行测试和未签名 Web 资源构建，正式签名和公证提交由本机完成。
