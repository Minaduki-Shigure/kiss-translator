# Kiss Translator 2.2.5-safari.2 · macOS

本次修订使用 **Developer ID Application** 证书为容器 App、Safari 扩展和 DMG 签名，发布者为 **Minaduki Technologies LLC**。App 与 DMG 分别提交 Apple 公证，通过后装订票据，并验证 Gatekeeper 接受最终安装包。支持 Apple Silicon 与 Intel，构建号为 `2020502`。

翻译功能继续基于上游 v2.2.5 及 `2.2.5-safari.1` 已记录的三个回移提交。扩展的版本提醒支持检测这次 Safari 修订。

**从开发签名版升级前，请先导出扩展配置。** 本次签名团队发生变化，跨团队升级时配置和网站授权能否自动继承尚未经用户资料实测。退出容器 App，将新版拖入“应用程序”替换旧版，推出 DMG 后再打开。检查 Safari 扩展设置、翻译服务和网站授权，需要时导入备份。

LocalAI、第三方服务插件和 PDF/EPUB 文件桥仍待移植。WebKit 下依赖 Origin / CSP 响应头改写的功能仍存在平台限制。安装步骤见包内说明和 [Safari 维护说明](../SAFARI.md)。

新增可恢复的 Developer ID 打包和公证流程，将每次上传的 UUID、审核日志、文件 SHA-256 和最终挂载验证记录保存到本地构建目录，便于维护者验证和继续未完成的公证。
